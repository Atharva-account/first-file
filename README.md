##Airbnb Dataset Analysis ##
📌 Project Overview
This project analyzes a dataset of Airbnb listings to:
 - Understand pricing patterns
 - Detect data problems
 - Identify unusual or incorrect entries
 - Explore host behavior
 - Prepare the data for future analysis or modeling
The dataset contains information about Airbnb listings in New York City.
<br>
<br>
##Problems Found in the Dataset##
#Some data is missing:#
 - name (16 missing)
 - host_name (21 missing)
 - last_review (10,052 missing)
 - reviews_per_month (10,052 missing)
#Price Problems:#
 - $0 price listings are likely errors.
 - $10,000 listings are extreme outliers.
 - Prices are highly uneven (very skewed).
Solution:
 - Remove or cap extreme prices.
 - Use price transformation (log) for modeling.
